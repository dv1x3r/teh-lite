# teh-lite

## Overview

A powerful and simple E-Commerce CRM Web Application starter project.

## Stack

- **Backend**: Go with Echo, templ, sql;
- **Frontend**: tailwind, htmx, alpine, w2ui (admin dashboard);

## Prerequisites

Make sure you have the following installed to run the project:

- **Go >= 1.27**

## Build

Follow these steps to build and run the project:

```sh
cp .env.example .env  # prepare the '.env' with default settings
make run              # build and the server
```
